    功能讲解

    公告
    记忆（视网）

    菜单里勾选知识库 → 「开始记忆」进入单词页。点任意单词弹出释义卡片，卡片上可点「不认识 / 认识」，内容分别收进「陌生」「熟悉」。

    右上「视网 32」调每页最多显示多少个词；「← 上一页 / 下一页 →」翻页。点开越多的词，之后出现得越频繁。

    批注（笔按钮）

    记忆页右上角的笔图标是批注模式开关。点亮后点单词不会弹释义，而是打开批注浮窗：可拖动头部移动、拖右下角改大小。

    「打字」栏写文字，可调字号（A− / A+）和黑、蓝、红三色；「手写」栏用 Apple Pencil、手指或鼠标书写，支持压感粗细，橡皮点一下擦掉整笔，「清空」抹掉这个词的全部批注。

    有关系批注的词在页面下方带金色下划线；批注随账号保存，换设备也在。

    知识库与记忆库

    「知识库」里每一行是一个词库，点行可开关、点「⋯」管理词条（增删改、重命名、搜索），点「×」删除；误删了可在「我的 → 恢复默认知识库」加回默认词库。

    「记忆库」可以建多个，每个都有自己的「陌生」和「熟悉」，点进去可逐条查看、复习或移出；下面的「朗读」打开后，点页面上任何一个词条都会自动读一遍，中、英、日、韩都按各自语言发音。

    导入

    「＋ 导入图片 / 文档 / 文字」支持拍照或选图识别、粘贴文本，解析后可存成新知识库，或直接并入「陌生」。

    视途（跨账号迁移）

    知识库页右上「视途」可把某个账号名下的知识库复制给另一个用户名。只复制、不搬走，来源账号的数据不会被删。

    视窗（好友 / 群聊）

    我的突触：每人一个固定的 8 位邀请码，显示在视窗顶部，点「复制」发给朋友。

    加好友：输入对方给你的突触码 → 添加，对方在「好友申请」里点接受，才成为好友。不能用名字直接加。

    聊天：点好友行进入对话，可发文字、语音，可分享知识库和记忆库给对方「收下」；「备注」可给好友改本地显示名，对方看到的还是原名。

    语音：聊天框左侧麦克风，点一下开始说，字幕实时显示；再点一下结束并发送。语音条显示时长和转写文字，点语音条可朗读。

    群聊：视窗切到「群聊」→「＋ 创建群聊」，起名并勾选好友（最多 8 位），对方收到邀请点「加入」即可。群里可发文字、语音，也能分享知识库和记忆库。

    交友：视窗切到「交友」，上半是收到的申请（可直接接受或忽略），下半是你发出的申请。处理过的申请会变灰并保留时间，记录随账号同步到云端，换设备也在。

    账号

    用户名：我的 → 用户名 → 修改。不能和别人重名（本机与云端都会查）；改名后进度、好友、群聊一起搬过去，旧名字释放，突触码不变。

    知识锁：开启后登录这个用户名需要先输密码，防止别人误登。

    星云：查看各设备登录情况、自动同步状态，最近 5 次云端记录可回退。

    切换用户：同一台设备可保存多个用户名，各自的进度分开存。

    同步说明

    改动会自动存到本机，并在联网时同步到云端；两台设备同时改会按新旧合并。断网时照常可用，联网后自动补传。
